\section{Limitations}
The random image-level split does not establish generalization to geographically unseen regions. Disjoint file paths cannot exclude spatial correlation or near-duplicate imagery. The study uses one dataset and RGB channels only, and evaluates five seeds on a shared test set rather than five independent geographic test sets. Seed standard deviation is a limited measure of experimental variability, not a confidence interval on deployment performance.

Synthetic Dirichlet partitions approximate label-frequency differences but do not reproduce all regional appearance, sensor, season or annotation shifts. The long-tail order is a fixed synthetic construction. Some clients lack entire classes, which reweighting cannot recover without additional evidence. Local-only models are not a federated-learning system, and no privacy guarantee is evaluated.

Pretrained and scratch models use different learning rates; GN receives a small learning-rate search rather than exhaustive optimization. Comparisons therefore describe the implemented training recipes. Loss hyperparameters are selected repeatedly on the same validation set, and the original Phase 1 test results were already inspected before this extension. The staged workflow prevents new test-driven selection within its execution but cannot make that historical test set unseen again. Missing original weights and the empty original pip-freeze files remain reproducibility limitations until the training machine supplies them.
